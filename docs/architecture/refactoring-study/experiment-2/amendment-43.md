# Amendment 43: require semantic and report completeness

Date: 2026-09-28.

The audit's 146 layout scopes, 22 contracts, and 21 mounts establish physical coverage but leave
composite scopes without per-leaf semantic decisions. An atomic leaf is a declared target node for
an independently meaningful policy, behavior, API, or boundary—not every directory. Decisions must
be explicit in the containing machine-checked contract; grouping-only folders inherit a parent
contract. A public decision may be a named API or explicitly empty, and the allowed dependency set
may be empty.

Completion also requires independently explorable Actual, declaration-derived Target, and Diff
report views, with report explorability a separate verdict. This clarifies proof requirements; it
changes no architecture permission or code behavior.
