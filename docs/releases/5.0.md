# DATAMIMIC CE 5.0

Install from PyPI using Python 3.11+:

```bash
python -m pip install datamimic-ce
```

Build protocol `5.0` (`BuildRequestV5`) is independent of the CE package version.

## Breaking changes

- Python minimum becomes 3.11. Python 3.10 compatibility shims are removed.
- XML is the persisted executable project; DM JSON is transient.
- Project Build replaces persisted Intent/Scaffold authoring. A project is a
  `datamimic.xml` entry, its included steps and `acceptance/build.json`, which holds
  expectations, roles and verification options. A ready Build lists every project
  file it read with its digest.
- Root scaffold/lint/dry-run/reference/capabilities commands move to the typed
  `datamimic authoring` subtree. Legacy Python authoring modules are retired.
- Catalog-backed errors carry stable identity and repair guidance. Some formerly
  generic exceptions now use portable typed exceptions with their native cause.

Re-author legacy intent models as projects (see [migration](../migrations/authoring-errors.md));
there is no automated migration. Existing XML execution is
supported. Compile support, bounded-proof eligibility and real external delivery
remain distinct; arbitrary Python execution cannot be made safe by target isolation.

## Agent entry point

The [Codex / Claude Code plugin](../agent_plugin.md) carries the consumer workflow
into other repositories. Shared setup prepares the project environment from PyPI
when needed. Authoring uses the CE CLI/optional MCP adapter or the Platform
project's server-owned MCP workflow. The runtime's live contracts remain authoritative. The plugin returns a model review with structure, counts,
key relationships, destinations and requirement-by-requirement evidence.
Unsupported or untested requirements remain visible even when Build is ready.

Executable models keep native field operations and rule parameters visible.
Typed Python functions handle justified algorithms with explicit inputs and
decision evidence. The [complex reference evaluation](../evaluations/complex-authoring-reference.md) defines
the complex reference gate.
