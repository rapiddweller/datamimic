# Assets

- `datamimic-logo-light.svg` and `datamimic-logo-dark.svg`: the DATAMIMIC wordmark for light and dark backgrounds. The README shows them with a `<picture>` element.
- `build-ready.tape`: a [vhs](https://github.com/charmbracelet/vhs) script that records `build-ready.gif`. Run `vhs docs/assets/build-ready.tape` from the repository root after you install CE. The recording needs `jq`.
